# BBC — broadcast design contract (read before editing any UI)

The app is a 24-hour news channel whose only story is the agent's own trading
book. Not a dashboard with a red accent — a broadcast.

## World
- Ground: `bg-studio` (#0a0d11) / `bg-studio-2` / `bg-desk`. Dark, always.
- Furniture: BBC broadcast red `bg-red` (#bb1919), `bg-red-deep`, `text-red-bright`.
  Red is page furniture (bars, straps, cut-ins), NOT a sprinkled accent.
- Text: `text-white` (headline), `text-ink` (body), `text-dim` (secondary),
  `text-faint` (tertiary). Rules: `border-rule` / `border-rule-lit`.
- Status lamps: `text-up` (green), `text-down`, `text-hold` (amber), `text-monitor` (blue).

## Type (classes defined in globals.css)
- `.headline` — Source Serif 4, the on-air headline voice. All big type.
- `.chyron` — Archivo 700, 11px, uppercase, 0.13em tracking. ALL small labels.
- `.strapline` — Archivo 600, the sub-headline strap voice.
- `.numeric` — tabular numerals. Use on every figure.
- Body copy is plain Archivo; measure 60–75ch.

## Primitives — use these, do not reinvent
From `@/components/ui`: `SectionLabel`, `Pill`, `Dot`, `Stat`, `Button`.
From `@/components/broadcast`: `LowerThird`, `Ticker`, `StudioClock`,
`LiveLamp`, `Slug`, `AnchorBull`, `BreakingCutIn`.
Panels use the `.monitor` class (a lit studio monitor: 14px radius, 1px
`border-rule`, one soft offset shadow). `.monitor-lit` for the active one.
Motion: `.cut-in` (clip-path wipe, how a lower third arrives) and `.cut-up`.

## Hard rules
- NO cards-of-icon-plus-heading-plus-text as page structure. Newsroom forms
  instead: running orders, rundown rows, straps, transcript columns, tape.
- NO nested cards, NO kickers/eyebrows above headings, NO gradient text,
  NO glass-blur decoration, NO `01 / 02 / 03` section numbers unless the
  sequence carries real information, NO emoji or unicode glyphs as icons.
- Icons come from `lucide-react` only, one stroke weight (2 or 2.5).
- Card radius 14px, pills for small controls only. Declare elevation once.
- Every state: loading, empty, error, hover, focus-visible, disabled.
- Responsive down to 375px. Nothing may scroll the page horizontally; wide
  tables/diagrams get their own `overflow-x-auto` container.
- A fixed ticker occupies the bottom 3.5rem of every page — do not place
  anything critical there; `main` already has `pb-14`.

## Product truth — non-negotiable
- Testnet alpha runs in **paper mode**: trades are simulated on Manifold.
  Any P&L figure must be visibly labeled as paper. Never write copy that
  implies realized cash.
- Chain is **Solana** (another agent is migrating the wallet layer right now).
  Never write "Arc", "EVM", "viem", or "Ethereum" in copy.
- Token is **$BBC**. The Bull Pool distributes agent proceeds to randomly
  drawn $BBC holders, weighted by holding, principal never at risk.
- Do not invent metrics, prices, dates, or a token mint address.

Copy voice: a news desk. Plain, confident, specific. Controls name their
action ("Put this market on air", not "Submit").
